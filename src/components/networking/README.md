# WebRTC-Based Peer-to-Peer Networking Hub

This component allows event attendees to join dynamic voice/video networking circles directly inside their browser using P2P connection logic.

## Usage

```jsx
import WebRTCNetworkingHub from './WebRTCNetworkingHub';

function App() {
  return <WebRTCNetworkingHub roomId="lounge-room" userId="hacker-42" />;
}
```
