- **Date:** {{event_date}}
- **Time:** {{event_time}}
- **Location:** {{event_location}}
- **Registration ID:** {{registration_id}}

Regards,  
{{organizer_name}}

## General Usage Guidelines

### Template Variables

Templates use variables enclosed in double curly braces.

Examples:

- `{{attendee_name}}`
- `{{event_name}}`
- `{{event_date}}`
- `{{event_time}}`
- `{{event_location}}`
- `{{registration_id}}`
- `{{contact_email}}`
- `{{organizer_name}}`

Replace every variable with the appropriate event information before sending an email.

### Email Best Practices

- [ ] Use a clear subject line.
- [ ] Address the recipient by name when appropriate.
- [ ] Keep important information easy to find.
- [ ] Use consistent event terminology.
- [ ] Include relevant dates and times.
- [ ] Include contact information.
- [ ] Verify every event link.
- [ ] Verify registration links.
- [ ] Verify feedback links.
- [ ] Avoid unnecessary personal information.
- [ ] Check formatting before sending.
- [ ] Test emails on desktop and mobile.
- [ ] Send test messages to the event team.
- [ ] Confirm recipient lists before sending.
- [ ] Respect unsubscribe preferences.
- [ ] Avoid misleading subject lines.
- [ ] Keep cancellation information clear.
- [ ] Keep payment information accurate.
- [ ] Review messages for spelling and grammar.
- [ ] Keep a record of important event communications.

### Before Sending

- [ ] Confirm the event name.
- [ ] Confirm the event date.
- [ ] Confirm the event time.
- [ ] Confirm the venue or event link.
- [ ] Confirm the recipient list.
- [ ] Confirm template variables are populated.
- [ ] Check all links.
- [ ] Check attachments.
- [ ] Confirm the sender address.
- [ ] Confirm the reply-to address.
- [ ] Send a test email.
- [ ] Review the rendered email.
- [ ] Obtain approval when required.
- [ ] Schedule or send the final email.

### Template Maintenance

- [ ] Review templates periodically.
- [ ] Remove outdated information.
- [ ] Update event terminology when necessary.
- [ ] Add templates for new communication scenarios.
- [ ] Review accessibility.
- [ ] Review links.
- [ ] Keep formatting consistent.
- [ ] Document newly introduced variables.
- [ ] Keep templates reusable.
- [ ] Avoid hard-coding event-specific information.
